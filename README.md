## 🚀 Cómo usar

1. Clona el repositorio
2. Sube los archivos en las carpetas:
   - **img/**: Foto de perfil + imágenes del dashboard
   - **pdfs/**: Hoja de vida y certificados
3. Publica en GitHub Pages

## 📄 GitHub Pages

Para ver tu portafolio online:
1. Ve a Settings → Pages
2. Selecciona "main" como rama
3. Tu sitio estará en: `https://jeissonskary.github.io/portafolio-jeisson`
